Game Setup

Host can adjust these before starting. They lock once the game begins.
Select a board size. You can start with the supported number of humans and AI: 2–4, 5–6, or 7–8. The 7–8 player Scattered Tiles and Cartographer boards change automatically when the eighth seat is occupied. Casual offers 4-player and 5–6-player maps.
Classic 5–6 uses paired turns (Player 1 rolls + acts, then Player 2 acts). Player 2 may only trade with the bank. Requires 5–6 players and uses 11 ports.
Seafarers 5–6 scenarios use paired turns like the classic 5–6 rules (Player 1 rolls + acts, then Player 2 acts). Player 2 may only trade with the bank. Requires 5–6 players and uses 11 ports.
7–8 player maps can fill empty seats with AI up to the selected player count. Cartographer and Scattered Tiles use the seven- or eight-player inventory selected under Number of players. Custom Map remains editable. Unranked only.
