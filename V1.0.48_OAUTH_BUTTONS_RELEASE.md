# Hex Settlers V1.0.48 — Four branded OAuth buttons

- On the login and registration screens, Google, GitHub, Cloudflare, and Discord share one equal-width, four-column row at desktop, mobile, and Discord Activity sizes.
- All buttons display local SVG provider logos and their short, readable names, without dependence on external icon CDNs.
- Provider availability, signup, authorization, and secure account linking are unchanged; unavailable providers continue to be hidden by server-provided configuration.
- Updated PWA offline asset cache to include the four logos.
- Version updated from V1.0.47 to V1.0.48, preserving the existing automatic GitHub/Cloudflare build-version scheme.
- Bundled Discord Activity JavaScript and SHA-256 checksum remain part of this complete source ZIP.

## Deploy

Copy the contents of `Hex-Settlers/` into the existing GitHub repository root, preserving Cloudflare secrets and the existing `.git` directory. Push as usual. Verify `public/icons/oauth/` includes four SVGs and that `public/discord-activity.bundle.js` and `.sha256` are committed.

## Validation

Run `npm run check:discord-bundle` and `node --test test/v1048-oauth-logos-layout.test.js`. For visual verification, open the login and registration screens at desktop and mobile widths with OAuth configured, and confirm all four provider buttons occupy one row with the appropriate icons. No new secrets or redirect URLs are required for this visual change.

Brand logos are used solely to identify the login provider. Monochrome GitHub/Cloudflare/Discord icon shapes obtained from the Simple Icons project (https://github.com/simple-icons/simple-icons), with their provider colors adapted for this dark interface.
