# V1.0.50 — New Shores randomization and starting-island restrictions

- Both supplied 5–6 and 7–8 layouts retain their fixed sea mask and separate island shapes. Land resource hexes are reshuffled for each map generation; number discs are independently reshuffled using the original reference inventories.
- Exactly three gold fields are placed randomly on smaller islands (spread across distinct smaller islands wherever possible). No gold may be placed on the largest starting mainland.
- The 5–6 map's single desert moves randomly within the mainland; the 7–8 map retains its original terrain inventory without a desert.
- Human, AI, and turn-timeout setup settlements on both maps are restricted to the dynamically identified largest island. The original four-player Heading for New Shores restrictions remain unchanged.
- Regular Seafarers +2 VP new-island settlement exploration applies under the existing exploration-points toggle, including challenge games. Daily/weekly challenge seeds retain deterministic maps for all players in the same period/capacity.
- Added regression tests for island setup, gold placement, terrain randomization, numbers, and inventory.

Validation: server syntax check passed; targeted New Shores + challenge-map suites passed (7/7). Fresh dependency installation/build could not be run in the current offline environment, so the existing generated browser/Discord assets are retained; no browser bundle code was changed in this release.
