Getting started & what each accelerator actually does
  1. Detect NVIDIA CUDA: use the GPU detection button. If CUDA is missing, install the correct PyTorch build in your selected Python interpreter.
  2. Start with 20–50 games: use Standard scenarios, 2 concurrent games/candidate, checkpoints every 10–25 games. Verify the counters and logs before running 20,000.
  3. Use Pause: the trainer finishes the next checkpoint and exits safely. Select that run in the drop-down to resume; Emergency Stop loses the current uncommitted batch.
  4. Check GPU utilization: your RTX 3090 Ti works on batched neural weight optimization; all full-rule game turn simulations currently run on the CPU.
  5. Native CUDA parity: install NVIDIA CUDA Toolkit and Visual Studio C++ tools, run scripts\cuda-exact\Build-Exact-CUDA.cmd, then select CUDA and run the parity check. A passing check verifies only the implemented transitions, not a full match.
  6. Exact full GPU game simulation: requires translating and verifying every authoritative transition in the ~16,000-line game server. The experimental surrogate arena is intentionally isolated from your real trained model.
