# Hex Settlers V1.0.51 — scenario consistency, New Shores, localization

## Scenario and map fixes
- Standardized 4, 5–6, and 7–8 Seafarers scenario dropdown order: Islands, Through the Desert, Fog Island, Heading for New Shores, Cartographer, Scattered Tiles, Custom Map.
- Corrected the UI's allowed 5–6-player selection set to include Heading for New Shores; previously, it displayed Six Islands even when the preview represented New Shores.
- Corrected `uiMapModeFromRules()` to detect Heading for New Shores 5–6 as a 5–6-player board, avoiding the mismatched four-player selector.
- Kept scenario-family mapping on player-count changes (including the New Shores variant).
- Updated scenario default VP calculation and resource bank calculation for New Shores 5–6/7–8.
- Removed the 32 sea hexes comprising the exterior ring of 7–8 Heading for New Shores, resulting in 65 total hexes (48 land and 17 interior sea). Interior sea corridors and existing land positions are preserved.
- Distributed all New Shores 6/8 number tokens to non-gold land tiles only, while retaining terrain randomization, offshore gold-field restriction, number counts, and initial settlement mainland restrictions.

## Localization improvements
- Expanded the curated French/Spanish/German UI dictionary with 103 screenshot-based and other recurring phrases. The additions cover lobby setup, AI controls, game toolbar, resource panels, tutorial prompts, player activity, development cards, and statistics.
- Added full document-body translations for the current Terms of Service and Privacy Policy to Spanish, French, and German. These are informational translations; English is the authoritative document. Legal review by qualified local-language counsel is still recommended.
- The legal-document overlay uses the same translations rather than depending on the iframe or headings-only translation; changing locale while the overlay is open will update its contents.
- Other supported languages retain the existing interface vocabulary and translated legal headings. Their complete legal-document body translations remain outstanding; do not claim full coverage.
- Remaining dynamically generated UI strings may still fall back to English. Preserve human/player content and game protocol values rather than blindly machine-translating them.

## Build and tests
- TypeScript bootstrap compilation and Discord Activity bundle generation/verification succeeded.
- Fourteen targeted lobby, New Shores, tutorial tests passed, including repeated gold-hot-number checks and the 65-hex 7–8 board check.
- Full historic test suite: 500 passed, 32 failed. Several failures are stale version assertions, missing npm `ws` dependency in the environment, and older tests with incompatible globals. These are not represented as passing tests.
- Source tree, existing generated browser assets, and deploy configuration retained.
- The checked-in build-version counter is V1.0.50; the configured successful Cloudflare build increment yields V1.0.51.
