# Hex Settlers V1.0.49 — New Shores and legal document viewer

## Maps
- Added Heading for New Shores presets for 5–6 and 7–8 players based on the supplied axial JSON layouts; left the existing four-player map intact.
- Preserved the resource counts and reference token inventories (38 discs on 5–6, 48 on 7–8) and randomized number placement per board generation.
- Added both presets to the appropriate game-setup scenario dropdown and included New Shores in the shared-scenario Daily/Weekly Challenge family pool.
- Daily and weekly challenge maps continue using seeded generation and Balanced Bag dice.
- Each supplied JSON includes an external sea border (88 and 97 hexes total), so the full rendered footprint is larger than the component-card inventory (58 and 65 hexes, respectively).
- Nine generated ports (five 2:1 and four 3:1) are supported by both presets, matching the component-card port inventory; supplied JSON had no placed ports.

## Legal pages and languages
- Replaced a CSP-blocked legal iframe with a same-origin document fetch and DOM render, preserving links to original full legal documents.
- Added dark-mode styling and scrolling for the document body in the modal.
- Embedded the existing language system on standalone Terms of Service and Privacy Policy pages.
- Added 61 additional common UI/legal/challenge labels for Spanish, French and German; other languages retain previously supported terms and fallback to English where a translation is missing.
- Full legal paragraph translations are NOT complete. The English legal content remains unchanged; legal text should be reviewed by qualified translators prior to declaring full translation support.

## Validation
- TypeScript/Discord Activity build passed; syntax checks passed; challenge maps focused unit tests passed.
- Full legacy suite has pre-existing assumptions about pinned historic versions and requires runtime dependencies; it did not pass in this environment.
